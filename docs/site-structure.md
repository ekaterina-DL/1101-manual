# Структура сайта-мануала

Статус: собрана 2026-09-23 по образцу родственного проекта «Заявки 1075–1077» (структура `site/` + `sources/` + `docs/`, дизайн-система, поиск). Изначально 3 страницы; 05.11.2026 выросла до **5 страниц** — `criteria.html` разделена на общую страницу критериев и две специализированные (коллаж / последовательное-два видео), см. ниже.

Навигация — как в референс-проекте: слева страницы сайта, справа разделы текущей страницы.

Важное правило (наследуется от референс-проекта): **на сайте нет персоналий**. Текущие источники (обе инструкции) персоналий и не содержат — правило актуально на будущее, если в `sources/`/`docs/` попадёт переписка с именами.

## Почему 5 страниц, а не 3 (решение от 05.11.2026)

Проект работает с **четырьмя «пулами» заданий** — два типа видео (видеоколлаж / последовательное-два видео) на двух источниках (YouTube / Vimeo). Правила по типу видео одинаковы независимо от источника, разница только в формате самой ссылки. Раньше всё жило в одном `criteria.html`, организованном по источнику — это запутывало, так как коллаж есть и на YouTube, и на Vimeo. По явному решению пользователя страница разделена **по типу задания**:
- `criteria.html` — только общие критерии (длительность, человек в кадре, повторы, ИИ и т. п.), одинаковые для всех четырёх пулов, плюс объяснение структуры пулов.
- `criteria-collage.html` — всё специфичное для коллажа (границы, масштаб, состав кадра, зеркальность, ориентация), оба формата ссылки, все 7 официальных примеров из базовой инструкции (они все про коллаж).
- `criteria-sequential.html` — всё специфичное для последовательного/двух видео (обязательный комментарий с тайм-кодом, правило «не должно быть коллажем», парное/групповое движение — новое из инструкции 02.11.2026), оба формата ссылки.

## 1. Обзор проекта (`overview.html`)
- Что за проект: видео с идентичным движением «до/после» CGI, цель 1000 видео, два типа задания (коллаж / последовательное-два видео), два источника (YouTube / Vimeo) — четыре пула, пояснение «CGI ≠ ИИ»
- Термин «видеоколлаж» — один из двух типов задания: граница по центру, равный масштаб частей, ссылка на `criteria-collage.html`
- Два формата — рабочие задания и экзамен: разница интерфейсов (скриншот экзамена — с 12.10.2026 включает шаг «отметить ориентацию», как и в рабочем задании), цифры экзамена (20 заданий, 15 мин/задание, проходной балл 17/20)
- Как устроена проверка: 100%-ная валидация, что именно проверяет кнопка «Проверить ссылку»

## 2. Критерии отбора видео (`criteria.html`) — общие
- Таблица-обзор четырёх пулов (тип задания × источник) со ссылками на специализированные страницы
- Callout «Запрещённые сюжеты» (курение/алкоголь/запрещённые вещества/насилие, кроме постановочных драк)
- Критерии по группам, общие для всех пулов: длительность видео и движения; человек в кадре (кто выполняет движение — человек/антропоморфное существо/млекопитающее, активность движения, различимость — включая затемнённый силуэт, текст/предметы/выход за кадр, рамки, вотермарки); съёмка и обработка (скорость, движение камеры, отсутствие зелёного экрана, повторы движения, происхождение видео — ИИ vs CGI vs анимация, распад на полосы)
- «Несколько человек в кадре» сюда не входит — формулировки разные для коллажа и для последовательного/двух видео, см. соответствующие страницы

## 3. Коллаж (`criteria-collage.html`)
- Формат ссылки и интерфейс для обоих источников (Vimeo: `vimeo.com/ID` / `player.vimeo.com/video/ID`, со скриншотом от 27.10.2026; YouTube: `www.`+`/shorts/…` или `/watch?…`, без отдельного актуального скриншота), ориентация (2 чекбокса), кнопка «Проверить ссылку»
- Критерии, специфичные для коллажа: граница между частями (включая неподвижность), масштаб частей, состав кадра (ровно 2 части), реальная съёмка хотя бы в одной части, расположение в частях (без зеркалирования), несколько человек в кадре (передний/задний план — формулировка от вопроса 15)
- Разбор всех 7 официальных примеров из базовой инструкции — видео + вердикт (пример 1 обновлён заказчиком 30.09.2026, пример 3 обновлён 09.10.2026)
- Чек-лист перед отправкой — коллаж

## 4. Последовательное / два видео (`criteria-sequential.html`)
- Формат ссылки и интерфейс (2 поля ссылок + поле комментария у каждой, комментарий с тайм-кодом **обязателен всегда**, ориентации нет), обновлено инструкцией от 02.11.2026
- Новое правило: «сбору не подлежат видеоколлажи» — со ссылкой на `criteria-collage.html`
- Критерий «несколько человек в кадре» — новая формулировка от 02.11.2026: идентичные движения по отдельности, либо парное/групповое движение в связке
- Примеры из инструкции 02.11.2026 — 5 штук; у примеров 1–3 пока нет видеофайлов (заглушки с текстом, ждём от пользователя), примеры 4–5 переиспользуют видео с официальной страницы коллажа (Harry Potter, Аватар) с новой подписью — показывают, что коллаж для этого пула не подходит
- Чек-лист перед отправкой — последовательное / два видео

## 5. Как искать видео (`search-tips.html`)
Добавлена 2026-09-24 по просьбе пользователя. 15 лайфхаков по поиску видеоколлажей в четырёх группах: поиск на самом видеоисточнике (запросы в кавычках, название фильма + VFX breakdown, каналы студий спецэффектов, похожие видео, шортсы, фильтры, хэштеги), поиск через Google (оператор `site:` — адрес видеоисточника назван описательно, без слова «YouTube»), синонимы и уточнения по действию человека, быстрый отсев (смена кадров вместо коллажа — с оговоркой про формат «последовательное видео», подборки со склейками, признаки ИИ, личный список собранных сцен). Правил не вводит — ссылается на `criteria-collage.html`/`criteria-sequential.html`. Предупреждение в начале: приёмы — только для YouTube, у Vimeo другой интерфейс поиска.
