# Бриф проекта

Сайт-мануал для асессоров Data Light, которые собирают ссылки на видео с идентичным движением «до/после» CGI для датасета Kandinsky (заявка 1101) — кадры из фильма/после CGI и те же кадры до наложения спецэффектов, на фоне зелёного или синего экрана (или наоборот). Чаще всего это видеоколлаж (ролик, разделённый на две части), но с 15.10.2026 заказчик разрешил ещё два формата — одно видео с «до»/«после» последовательно и два отдельных видео. Цель — 1000 видео.

В отличие от родственного проекта [«Заявки 1075–1077»](https://ekaterina-dl.github.io/1075-1077-manual/) (три параллельные заявки, задание — комплект из 5 ссылок на одно движение), здесь одна заявка и одно задание — одна или две ссылки (зависит от формата видео), а не комплект из пяти.

Задания (включая экзамен) асессоры выполняют в личном кабинете на платформе Tagme — той же, что и в заявках 1075–1077 (подтверждено пользователем 2026-09-23); доступ к ней выдаёт руководитель группы Data Light.

Уникальность сайта — он объединяет в одном понятном источнике официальную инструкцию для рабочих заданий и инструкцию для экзамена, показывает расхождения между ними и разбирает все 7 примеров из инструкций на реальном видео.

Мануал общий и не привязан к конкретным людям — см. правило «нет персоналий» в `CLAUDE.md`.

Сайт опубликован на GitHub Pages (2026-09-23): https://ekaterina-dl.github.io/1101-manual/ — репозиторий https://github.com/ekaterina-DL/1101-manual (см. `README.md`).
