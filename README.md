# Заявка 1101 (Kandinsky. Движения — зелёный экран)

Сайт-мануал для асессоров Data Light по сбору ссылок на видео с идентичным движением «до/после» CGI (кадр из фильма/после CGI + тот же кадр до эффекта на зелёном/синем экране; чаще всего — видеоколлаж, но не только) для датасета Kandinsky.

Живой сайт: **https://ekaterina-dl.github.io/1101-manual/**

Чтобы посмотреть сайт локально, открой `site/overview.html` в браузере. Исходники от заказчика — в `sources/` (не для публикации, см. `CLAUDE.md`), история и планы проекта — в `docs/`.
