# Заявка 1101 (Kandinsky. Движения — зелёный экран)

Сайт-мануал для асессоров Data Light по сбору ссылок на видеоколлажи (кадр из фильма/после CGI + тот же кадр до эффекта на зелёном/синем экране) для датасета Kandinsky.

Сайт пока не опубликован — собран только локально.

Чтобы посмотреть сайт локально, открой `site/overview.html` в браузере. Исходники от заказчика — в `sources/` (не для публикации, см. `CLAUDE.md`), история и планы проекта — в `docs/`.
